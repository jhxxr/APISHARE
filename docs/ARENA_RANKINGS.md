# 公开模型排行榜

公开排行展示每日同步至本地的 Arena 官方历史快照。页面读取本地公开 API，缓存为空时显示暂无数据，获取失败时保留最近成功快照，不生成推断排名。

- 保留源榜模型名称、分数、名次和并列名次，筛选和分页不重新编号。Agent IPS 与 Arena Rating 使用各自原始尺度。
- “本站已接入”按实际渠道模型映射后的型号与日期版本匹配。明确的思考强度差异会提示，不代表本站调用复现榜单测试配置。
- 不同日期、Pro/Mini、Preview 等版本区别仍然保留。本站没有对应榜单版本的模型单独展示，不借用其他版本的分数。
- 官方 DeepSeek 入口的已核验滚动别名保留版本标注，第三方同名渠道不继承该版本承诺。
- 排行榜展示与实际请求转发相互独立。客户端指定模型，网关仅在该模型的可用站点渠道之间调度。

榜单同步与缓存、模型接入匹配和分页筛选继续由原有后台任务与公开接口提供。
