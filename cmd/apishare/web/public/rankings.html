能力分是路由参考，不是官方榜单

与智能路由共用六维能力画像。来源可能是内置校准、模型族推断、同步数据或站点覆盖；每个模型均标明来源。分数不是本站重新运行公开基准所得的实测成绩。

02

不同任务，值得不同的第一名

综合分按软件工程 24%、前端 UI 12%、数学推理 22%、工具调用 18%、写作知识 14%、长上下文与多模态 10% 加权。也可按单项能力独立排序。

03

在线表现，单独看待
